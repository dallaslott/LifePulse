# Reviewing Life Pulse on this computer

Nothing in this folder is published automatically from your computer.

## Open the local preview

1. Double-click `index.html`.
2. Your normal browser will open the local Life Pulse page.
3. Enter a sample profile and select **Launch Tracker**.
4. Review the new **Today's Life Pulse** panel near the top of the results.
5. Close the browser tab when finished.

Because this is a local file rather than the published website, some web services may use their built-in fallback during review. The page layout, calculations, controls, sports corrections, and fallback behavior remain available. Once the approved version is published, GitHub will generate `live-data.json` and the daily panel will prefer that same-site feed.

## What will happen later

When you approve this version, the GitHub Pages publishing source will be changed to **GitHub Actions**. The included workflow will refresh the daily data and redeploy the same `dallaslott.github.io/LifePulse` address every three hours.

Do not change the GitHub Pages settings until you are ready to publish.
